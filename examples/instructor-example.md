# Instructor mode example

**Provenance:** newly written, public-safe illustration; 13 September 2026. This is not a retained benchmark transcript or a unique correct answer.

**Question:** Design a product for people moving to a new city.

**User's Stage 2B answer:**

> I would segment movers into young people, frequent movers, and people who want community. I'll choose young people because it feels like the biggest group.

**Instructor response:**

If you fix only one thing, fix the segmentation logic. These groups mix age, moving frequency, and motivation, and “biggest” does not explain which need or product opportunity is strongest.

**Reusable framework pattern**

`Motivations → Segmentation dimensions → Synthesize meaningful segments → Test needs/product consequence → Prioritize → Persona`

Which motivations and circumstances most change what movers struggle with, and what 2–4 meaningful groups emerge when you combine only those dimensions?

---

The Instructor diagnoses the highest-value issue, teaches the reusable principle, and asks the user to repair the answer. It does not choose a segment for them. If the user explicitly asks for a model answer, the instruction file permits one.
